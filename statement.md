# Project Statement

## 1. Problem Statement

Managing student information, academic performance, evaluations, attendance, and
class analytics can be difficult when these activities are handled manually.

The University Portal project provides a simple Python-based system for managing
student academic information through different user roles. The system allows
students to view their academic information, teachers to manage evaluations and
marks, and administrators to manage users and system status.

The project aims to provide a structured and easy-to-use portal for handling
student performance and academic-related activities.

---

## 2. Scope of the Project

The scope of this project includes:

- User authentication and login.
- Role-based access for students, teachers, and administrators.
- Student dashboard for viewing grades and schedules.
- Teacher functionality for recording and managing student evaluations.
- Calculation of student grades and GPA.
- Calculation of class performance statistics.
- Display of class average, highest score, and lowest score.
- Display of pass/fail information and grade distribution.
- Basic administration and user management.

The project is designed as a Python-based application and uses in-memory data
structures for storing information during program execution.

---

## 3. Target Users

The main target users of the system are:

### Students
Students can:
- Log in to the system.
- View their grades and schedule.
- View their performance information.
- View their course evaluation results.
- View their grade and GPA information.

### Teachers
Teachers can:
- Log in to the system.
- Record student scores.
- View class marksheets.
- Manage evaluation records.
- View class performance analytics.

### Administrators
Administrators can:
- Log in to the system.
- Add new users.
- Assign user roles.
- View the system status.

---

## 4. High-Level Features

### 4.1 Authentication
The system provides login functionality and identifies users according to
their assigned roles.

### 4.2 Role-Based Dashboards
Different dashboards are provided for students, teachers, and administrators.

### 4.3 Student Performance
Students can view their grades, evaluation results, GPA, and performance
summary.

### 4.4 Evaluation Management
Teachers can create, view, update, and delete student evaluation records.

### 4.5 Grade and GPA Calculation
The system calculates letter grades and GPA based on student performance.

### 4.6 Class Analytics
The system provides class-level statistics such as average score,
highest score, lowest score, and pass/fail counts.

### 4.7 User Management
Administrators can create users and assign roles such as student, teacher,
or administrator.
